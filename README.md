# Pocket Snake

A retro LCD-style snake game in a single HTML file: no build step, no dependencies.

**Play:** https://npsquared.github.io/PocketSnake/

## Features

- 9 speed levels: food is worth the level number in points, and faster levels score more.
- 5 mazes: None, Box, Tunnel, Rails and Pillars. The board wraps around wherever there is no wall.
- 3 modes. **Classic** keeps one speed all game. **Ramp** speeds the snake up a notch every 10 foods, and each notch adds a point to every food. **Campaign** does the same, and also moves you on to the next maze at every notch, starting from the maze you picked.
- Bonus critters appear after every 5 pieces of food. Catch them before the countdown ends.
- A top-10 high-score table with 3-letter initials. On this site the scores are saved in each player's browser.
- Keyboard, swipe and on-screen pad controls. The board reshapes itself to fit phones held upright.

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Steer | Arrows, WASD, or 2 4 6 8 | Swipe the screen or use the pad |
| OK / select | Enter or 5 | Tap the screen or the pad's centre |
| Pause | P, Space or Esc | PAUSE button |
| Sound on/off | M | SOUND button |

## Run it locally

Open `index.html` in any browser.
